SFTP Download Client PoC - Build / Deploy
========================================

직접 빌드 (Visual Studio 불필요)
1) MinGW-w64 x64 g++ 설치
   winget install -e --id BrechtSanders.WinLibs.POSIX.UCRT
2) cd /d D:\Cursor\SFTP
3) powershell -ExecutionPolicy Bypass -File scripts\build_direct.ps1
   결과: dist\Client.exe (정적 링크, 별도 DLL 없음)

아래는 Visual Studio 솔루션(SftpClient.sln)을 쓰는 경우입니다.

요구사항
- Visual Studio 2015 (v140 toolset) 이상
  * VS2017/2019/2022 사용 시 솔루션을 열고 Platform Toolset 을
    설치된 도구 집합으로 Retarget 하세요. (/MT 설정은 유지)
- Windows 10/11 x64
- Windows SDK (VS2015 기본 구성)

구성
- libssh2 1.11.1 정적 링크
- Crypto backend: WinCNG (+ ECDSA)
- CRT: /MT (Release), /MTd (Debug)
- 배포 시 DLL 불필요 (목표)

빌드
1) "VS2015 x64 Native Tools Command Prompt" 실행
2) cd /d D:\Cursor\SFTP
3) scripts\build.bat
   또는
   msbuild SftpClient.sln /p:Configuration=Release /p:Platform=x64

배포물 (dist\)
- Client.exe
- config.ini
- LICENSE_libssh2.txt

config.ini
- HostFingerprint 필수. 미등록/불일치 시 즉시 종료.
- 파일은 RemoteFile/LocalFile 또는 RemoteFileN/LocalFileN (1~20)

Host fingerprint 구하기 (서버)
  ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub -E sha256
  ssh-keygen -lf /etc/ssh/ssh_host_rsa_key.pub -E sha256

중요 제한
- WinCNG 백엔드는 Ed25519 host key 를 지원하지 않습니다.
  서버에 RSA 또는 ECDSA host key 가 활성화되어 있어야 합니다.
  (일반적인 OpenSSH 설치는 rsa/ecdsa/ed25519 키를 모두 가집니다.)

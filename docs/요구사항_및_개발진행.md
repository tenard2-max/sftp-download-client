## 1. 프로젝트 목적

Linux SFTP 서버에 접속하여, `config.ini`에 사전에 지정된 파일 **1~20개**를  
Windows 로컬 경로로 **사용자 조작 없이 자동 다운로드**하는 PoC(Proof of Concept) 프로그램이다.

- 최종 산출물 형태: `Client.exe` + (필요 시 DLL) + `config.ini`
- 고객 PC에 별도 Runtime/프로그램 설치 **금지**
- Visual Studio가 없는 PC에서도 실행 가능해야 함
- 배포 용량 목표: **10MB 미만**

## 2. 전체 요구사항 요약

### 2.1 개발 환경

| 구분 | 요구사항 | PoC 반영 |
|------|----------|----------|
| 언어 | C++ | C++ Console Application |
| IDE | 최초 VS2008 명시 → 협의 후 **VS2015** | `PlatformToolset = v140` |
| 플랫폼 | Windows 10/11 x64 | x64 only |
| 금지 기술 | C#/.NET, Python, Java, Node.js (제품) | 제품에 미사용 |
| 실행 의존성 | VC++ Runtime 미설치 PC 지원 | **`/MT` 정적 CRT** |

> 참고: VS2008은 최신 libssh2/Win10·11 배포 조건과 호환이 어려워,  
> **배포 조건(/MT, Runtime 미설치)을 유지한 채 VS2015로 상향**하기로 확정함.

### 2.2 배포 조건

- 정적 링크 우선
- 불가 시 필요 DLL만 `Client.exe`와 동일 폴더 배포
- 목표 배포물:
  - `Client.exe`
  - `config.ini`
  - `LICENSE_libssh2.txt` (BSD 고지)

현재 설계는 **libssh2 정적 링크 + WinCNG**로 DLL 없이 배포하는 것이 목표이다.

### 2.3 기능 요구사항 (자동 실행 흐름)

프로그램 실행 시 GUI/목록 조회/업로드/파일 선택 **없음**. 아래만 수행한다.

1. `config.ini` 읽기  
   - Host, Port, User, Password, HostFingerprint  
   - RemoteFile/LocalFile 또는 RemoteFileN/LocalFileN (1~20)
2. SFTP 서버 TCP/SSH 연결
3. 서버 SSH Host Key 수신
4. 서버 Host Key의 SHA-256 Fingerprint 확인
5. `config.ini`의 HostFingerprint와 비교  
   - 일치 → 계속  
   - 불일치 → 즉시 종료 + 오류 로그  
   - **미등록 → 연결 금지**
6. ID/PW 사용자 인증
7. SFTP 세션 시작
8. RemoteFile 존재 확인
9. LocalFile로 다운로드
10. 다운로드 성공 여부 확인
11. SFTP/SSH 연결 정상 종료
12. 프로그램 종료

### 2.4 보안 요구사항

- SSH/SFTP 프로토콜 **직접 구현 금지**
- 검증된 라이브러리 사용
- Host Key 검증 **생략 금지**
- 모든 Host Key 무조건 허용 코드 **작성 금지**
- Fingerprint 불일치 시 즉시 연결 종료

### 2.5 오류 처리 (콘솔 메시지)

다음 상황을 명확히 표시해야 한다.

- 서버 연결 실패
- Host Key 불일치
- HostFingerprint 미등록
- 로그인 실패
- RemoteFile 없음
- LocalFile 생성 실패
- 다운로드 실패
- 다운로드 성공

## 3. 라이브러리 선정

### 3.1 선정 결과

**libssh2 1.11.1 + WinCNG crypto backend (정적 링크)**

### 3.2 선정 이유

| 기준 | 평가 |
|------|------|
| 검증된 SFTP/SSH 클라이언트 | curl 등에서 널리 사용 |
| 라이선스 | BSD-3-Clause → 상용 배포·소스 비공개에 유리 |
| 정적 링크 | 가능 |
| OpenSSL DLL | WinCNG 사용 시 **불필요** |
| Host Key / SHA256 | `libssh2_hostkey_hash(..., SHA256)` 제공 |
| VS2015 | 소스 포함 빌드 가능 |

### 3.3 검토했으나 제외한 대안

| 대안 | 제외 이유 |
|------|-----------|
| libssh | LGPL → 정적 링크 시 배포 의무 부담 |
| libcurl(SFTP) | 사실상 libssh2 의존 + 용량/의존성 증가 |
| OpenSSH 바이너리 호출 | 별도 프로그램 배포에 가까움 |

### 3.4 알려진 제한

- WinCNG는 **Ed25519 host key 미지원**
- 서버에 **RSA 또는 ECDSA** host key가 제공되어야 함  
  (일반 OpenSSH 설치는 보통 rsa/ecdsa/ed25519를 모두 보유)
- PoC에서는 `LIBSSH2_ECDSA_WINCNG`를 켜 Windows 10/11 ECDSA를 사용

## 5. config.ini 스펙

### 5.1 키 정의

| 키 | 필수 | 설명 |
|----|------|------|
| Host | O | SFTP 서버 주소 |
| Port | O | 기본 예: 22 |
| User | O | 계정 |
| Password | O | 비밀번호 |
| HostFingerprint | O | `SHA256:...` (미등록 시 연결 금지) |
| RemoteFile / LocalFile | 선택 | 단일 파일(1번으로 취급) |
| RemoteFileN / LocalFileN | 선택 | N=1..20 |

### 5.2 예시

```ini
Host=192.168.0.10
Port=22
User=testuser
Password=testpassword
HostFingerprint=SHA256:xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

RemoteFile1=/data/test.dat
LocalFile1=C:\SftpDemo\test.dat
RemoteFile2=/data/test2.dat
LocalFile2=C:\SftpDemo\test2.dat
```

## 6. 빌드 / 실행 방법

### 6.1 빌드

```bat
cd /d D:\Cursor\SFTP
scripts\build.bat
```

또는 Visual Studio에서 `SftpClient.sln` → **Release | x64** 빌드.

VS2017 이상을 쓰는 경우 Platform Toolset만 Retarget하고 `/MT`는 유지한다.

### 6.2 실행

1. `dist\config.ini`에 실제 서버/파일/fingerprint 기입
2. `dist\Client.exe` 실행
3. 콘솔 로그로 성공/실패 확인
